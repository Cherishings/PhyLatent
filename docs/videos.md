## Cube collapse diagnostics / Cube 坍缩诊断

[English MP4](../assets/videos/cube_three_cases_en.mp4?raw=true) · [中文 MP4](../assets/videos/cube_three_cases_zh.mp4?raw=true)

- **Invariance / 不变性：** Appearance changes alter the model's preference. 外观变化使模型对动作方案的偏好反转。
- **Distinguishability / 可区分性：** The model misranks actual outcomes relative to the goal. 模型误判真实结果与目标的远近关系。
- **Counterfactual dynamics / 反事实动力学：** Future prediction reverses an otherwise correct ranking. 预测未来时，原本正确的优劣排序发生反转。

The film includes diagnostic comparisons and side-by-side LeWM / PhyLatent execution.
